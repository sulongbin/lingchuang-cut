# 实现与内部模块

产品入口统一为 `lingchuang-cut`。技术标识、软件包名和第三方版权不能因产品改名而改写，否则会破坏安装、导入和许可证。

## 运行方式

优先复用当前项目已验证的工具链与版本。检查 ffmpeg、ffprobe、Python、Node 和专用无头浏览器。转写与图片生成使用宿主可用工具；未配置时明确报告，不假装已调用。

主时间轴采用 Remotion 时，以 `useCurrentFrame()` 和当前项目版本支持的插值/弹簧 API 驱动画面。人物视频的源时间必须与音频剪辑映射一致。内嵌网页动效不能直接依赖 CSS 自动播放或挂载后的墙钟时间。

本包没有复制许可尚未核实的主时间轴技能文档。安装环境已有 `remotion-best-practices` 时按任务读取对应文档；其他环境可通过官方文档 https://www.remotion.dev/docs/ 获取 API。软件本体按官方许可使用，本包的 MIT 许可不覆盖它。

## 模块加载

执行 `python scripts/modules.py list` 查看资料，执行 `python scripts/modules.py unpack <模块ID>` 展开到本技能的 `.runtime/<模块ID>/`，然后读取该目录的 `SKILL.md`。这些是保留原貌的第三方技术参考；其中默认创作模式不得覆盖用户已经确定的语言、比例、声音、浏览器偏好与本次任务范围。

| 模块 ID | 用途 | 何时使用 |
| --- | --- | --- |
| html-motion | HTML 动画与视频合成资料 | 制作可定位的图解、标题、转场 |
| shot-design | 镜头配方、示例实现与模板 | 需要具体镜头运动时选取单个配方，先读配方与对应实现 |
| diagram-motion | 数学与几何动画资料 | 流程机制、公式、图表推演 |
| interface-motion | 网页运动设计参考 | 借鉴缓动、弹性、视差；输出视频前改为时间驱动 |
| page-layout | 可视化页面编辑参考 | 确有编辑器或页面搭建需求时，普通口播通常不用 |

展开的资料可能包含额外依赖或参考资产。不要自动运行其中的部署、发布、安装和网络服务脚本；先明确当前任务是否需要。库中案例品牌、截图和音频不默认用作用户成片素材。

镜头模块封装的是源码与文档版，未携带示例音视频、图片和字体；具体省略项见展开后的 `LINGCHUANG_PACKAGING_NOTE.txt`。模板需要先替换为项目素材再运行，不能将缺少示例素材当成已经可以直接渲染。

## 工程约定

在原片所在项目内创建 assets、project、review、output；不要搬走原片。分镜记录源区间、目标区间、类别、台词、素材、动画与音频安排。

本机可用 `local-config.json` 配置 `asset_library` 和 `tools`；它只存本机路径，不是通用安装要求。公开仓库忽略该配置、展开缓存和媒体工程。

先输出代表帧验证，再渲染成片。遇到新增依赖先做短镜头验证，不直接启动整条长视频。

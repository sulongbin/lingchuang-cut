# 视觉与动画规则

先确定最终布局，再添加运动。每个镜头回答一个问题：观众需要注意哪里、理解什么变化？

## 动画选择

| 口播内容 | 适合画面 | 运动方式 |
| --- | --- | --- |
| 步骤、工作流程 | 节点与连线 | 顺序显现、路径描绘、当前节点强调 |
| 效率、增长、规模 | 条形、数字、对比 | 按真实数据变化，最后停留 |
| 核心结论 | 大字与简单示意 | 分层入场、关键词强调 |
| 操作功能 | 真实界面局部 | 推近、聚焦、平移，保留定位上下文 |
| 多个案例 | 素材卡片或分屏 | 前后景切换、景深与轻微视差 |
| 抽象机制 | 几何或概念图 | 形态变化、关系重组 |

别把所有观点都做成相同的卡片淡入。让真人、素材、图解与结论镜头产生密度变化。避免装饰性粒子、闪白、快速旋转抢走注意力。

## 排版与层级

采用一套字体、颜色与间距体系。竖屏标题、画中画、字幕和平台界面分别预留空间。信息过多时分镜表达，不靠缩小字体塞满。

背景黑色遮罩从约 20%–35% 不透明度开始，根据素材实际对比度调整；遮罩处于背景之上、文字与主体之下。不要用黑色遮罩掩盖过密或无重点的设计。

画中画位置由信息布局决定，可以在下方或角落，但不要随机跳动。迁移位置时平滑过渡，保持人物尺寸与视线方向合理。

## 导出约束

动画必须可按时间定位，同一时间点重复渲染应一致。网页滚动、悬停和真实时间触发的效果要改造成视频时间轴驱动。不要把网页预览流畅等同于视频渲染成功。

预览至少覆盖镜头入场、最复杂布局和出场。长镜头检查中段；画中画检查是否一直播放而非只在开头活动。

## 真实素材动效与 3D

优先将动画应用在用户真实视频、产品照片或录屏上：如局部推近、轮廓光、图层视差、前后对比及转场；录屏保持界面可读、真人播放与口型同步。按语义和观众注意力安排，不把特效套在每一镜。

需要产品图片时，优先实拍或用户素材；缺少时可在宿主支持的情况下按内容生成图片并标注示意，保存提示词和素材。静态产品图结合三维展台与透视可营造空间感，不称为可真实旋转的三维模型。

需要三维空间时，可在项目内使用已验证的工具链制作短预览并检查性能与成片；高级引擎、3D 依赖和图像生成服务不是本包自动安装的能力。已安装 ruic-motion-reel 时可参考其点云、排版和风格，独立测试只验证过横屏场景置于竖屏画布；其默认 1080p 场景遇到尺寸不匹配，使用前须自行验证。无需为普通剪辑强制使用该技能。
